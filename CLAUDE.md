# CLAUDE.md

Conventions for this repository live in [AGENTS.md](./AGENTS.md). Read it
before making changes.

Additional notes for agent-assisted sessions:

- Work through `ROADMAP.md` one milestone at a time, in order. If a
  milestone is blocked, say why rather than skipping ahead silently.
- Open a pull request per milestone. Never push directly to `main`.
- Do not scaffold beyond the milestone in scope. If the task says
  "Order Service", do not also write the Inventory Service.
- If a requirement is ambiguous, ask before implementing. Do not infer a
  technology choice that isn't in AGENTS.md.
- Report honestly what was and wasn't verified. "Tests pass" and
  "the stack starts" are different claims.
